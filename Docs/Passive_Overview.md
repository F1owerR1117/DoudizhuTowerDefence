# 被动技能总览（以代码实际实现为准）

> 本文档为被动系统的**唯一事实来源**，所有描述均按 `Assets/Scripts/Gameplay/Entities/UnitPassives*.cs` 的实际行为整理。
> 最后核对：26 个 `enable*` 开关 ↔ 26 条被动，无遗漏。

---

## 通用约定（先看这里，能解释大部分疑惑）

### 距离口径
| 判定方式 | 用于 | 说明 |
|---|---|---|
| **边缘距离** | 攻击范围、索敌、嘲讽、治疗、扇形溅射、骑兵、盾墙、伤害分摊 | 两碰撞体最近点之间的间隙，重叠为 0 |
| **圆形重叠** | 减速、君王光环、震波、死亡爆炸、圆形溅射、燃烧区域、弹道爆炸、Boss 技能 | 以自身中心为圆心的圆与目标碰撞体相交 |

> 边缘距离与圆形重叠的差别：后者实际覆盖比"同样数值的边缘距离"更远，约多出自身碰撞体半径。

### 高度掩码
每个单位有三个高度字段：

| 字段 | 含义 |
|---|---|
| `_unitHeight` | 我是什么高度（地面 / 空中） |
| `_canAttackHeight` | 我能攻击哪些高度 |
| `_canBlockHeight` | 我能阻挡哪些高度 |

**伤害类被动都会检查 `CanAttackHeight`；光环类默认不检查**（可用「光环通用」开关切换）。

### 伤害类型
| 类型 | 说明 |
|---|---|
| Physical / Special / Bomb / Burn | 吃盾墙减伤、护盾吸收、伤害减免 |
| **True（真实伤害）** | **无视**盾墙、护盾、减免 |

### 其他
- 伤害走批量队列（`DamageQueue`）时，帧末统一结算；处决在两处结算点都会判定。
- 对象池复用时，被动会在 `ResubscribeEvents` 重新订阅事件并重置计数。
- 单位回池/死亡会清除：高度覆盖、可攻击高度覆盖、引导状态。

## 逐条详情

### 1. 点杀 `enableSniper`
- **参数**：`sniperRangeBonus`（扩展射程，0 = 用索敌范围）、`sniperHpThreshold`（默认 0.3）
- **实际行为**：
  - 射程**内**的敌人：**无条件**按“血量百分比最低”优先选中（不看阈值）
  - 射程**外**、扩展射程内的敌人：只有血量 ≤ 阈值才可锁定，并对其使用扩展射程攻击
  - 两者都没有时，回退普通索敌
- **注意**：阈值只影响“越界”锁定，不影响射程内选人

### 2. 人海 `enableSwarm`
- **参数**：`swarmRadius`（默认 2）、`swarmDamagePct`（默认 0.5 = +50%/人）
- **实际行为**：**每帧**统计半径内友军数量，按数量**实时提升自身攻击力**（乘算，无上限）
  - 例：3 名友军 × 50% → 攻击力 ×2.5
  - 友军进出范围时立即变化，攻击力面板数字同步变化
- **注意**：**不含自己、不计建筑**；提升的是 `ATK` 本体，因此会同时影响普攻、溅射、震波、死亡爆炸等所有按攻击力计算的伤害
- 为减少开销，只在「人数变化」时才写入 Buff，数值结果与逐帧重算一致

### 3. 冲锋一击 `enableCharge`
- **参数**：`chargeMultiplier`（2.5）、`chargeCooldown`（6s）、`chargeSpeedMultiplier`（1.3）
  高度三项：`chargeHeightOverride`（自身高度）、`chargeBlockableByHeight`（可被阻挡）、`chargeAttackableHeight`（可攻击目标）
- **实际行为**：
  - 生成时立即进入冲锋；之后需「不在攻击中」且「距上次攻击 ≥ 冷却」才会重新进入
  - 冲锋期间移速提升、可覆盖三项高度关系
  - 下一次攻击命中时：伤害 × 倍率（以额外伤害形式叠加），随后退出冲锋并恢复高度
- **注意**：
  - 高度三项留空(0) = 不覆盖；**可攻击目标是“替换”而非“取交集”**
  - 冲锋首击的命中判定在被动触发**之前**锁定，因此“冲锋获得的高度”能正常打出伤害
  - `chargeBlockableByHeight` 为 0 时会回退为 `chargeHeightOverride` 的值；填 -1(Everything) = 任何有阻挡能力的敌人都能挡住

### 4. 君王光环 `enableKingAura`
- **参数**：`kingInterval`（5s）、`kingRadius`（3）、`kingPushDistance`（1）
- **实际行为**：每隔一段时间，把半径内敌方单位沿远离自身的方向推开指定距离（0.2 秒平滑位移），并播放特效
- **注意**：受「光环通用」开关控制，可只影响自己能攻击到的高度

### 5. 盾墙线 `enableShieldWall`
- **参数**：`shieldRange`（3）、`shieldDamageReduction`（0.2）
- **实际行为**：半径内**友军单位**受到的伤害 × `(1 - 减伤)`，**多个盾墙乘算叠加且无上限**
- **边界**：
  - **真实伤害不受减免**
  - **不保护建筑**
  - **不保护自身**（盾墙单位自己不吃自己的减免）
  - 距离按**边缘距离**判定

### 6. 嘲讽 `enableTaunt`
- **参数**：`tauntRadius`（5）
- **实际行为**：敌方索敌时，若同时满足以下三条，则优先锁定嘲讽源：
  1. 自己在嘲讽源的半径内
  2. 嘲讽源在自己的攻击范围内
  3. 自己能攻击到嘲讽源的高度
- **多个嘲讽源**：取**最近**的一个（边缘距离）
- **正在攻击的敌人**：不会被打断，但本次攻击结束后会切换到嘲讽目标

### 7. 死亡爆炸 `enableDeathExplosion`
- **参数**：`explosionRadius`（2）、`explosionDamagePct`（1.0）
- **实际行为**：死亡时对半径内敌人造成伤害
- **边界**：只伤害**自己能攻击到的高度**；**敌方建筑也会被波及**

### 8. 护盾 `enableShieldAbsorb`
- **参数**：`shieldAmount`（200）
- **实际行为**：生成时获得一次性护盾，按点数吸收伤害
- **边界**：
  - **真实伤害直接穿透护盾**
  - 若一次攻击被护盾**完全吸收**（血量没变），**不会触发处决**

### 9. 减速光环 `enableSlowAura`
- **参数**：`slowRadius`（3）、`slowPercent`（0.3）、`slowDuration`（2s）
- **实际行为**：范围内敌人移速 × `(1 - slowPercent)`；离开范围后仍持续 `slowDuration` 秒
- **多光环**：**取最强**（更小的移速乘数），不叠加
- **注意**：受「光环通用」开关控制；默认对范围内所有敌人生效（不看高度）

### 10. 击晕 `enableStunOnHit`
- **参数**：`stunDuration`（1s）、`stunEveryNHits`（1 = 每次攻击都触发）
- **实际行为**：攻击命中时给目标施加眩晕；眩晕期间目标停止行动并**打断其当前攻击**
- **触发计数**：按**攻击次数**累计，达到 `stunEveryNHits` 才触发一次；多目标一次攻击命中多个敌人**只算一次**
- **多目标**：触发时对本次命中的每个目标独立施加眩晕

### 11. 快速连击 `enableBurstAttack`
- **参数**：`burstHitCount`（3）、`burstAttackIntervalMult`（1）、`burstCooldown`（2s）
- **实际行为**：累计攻击 N 次后**自我眩晕**冷却一段时间，计数归零
- **注意**：
  - 不是“首次攻击后进入快攻”，而是**持续累计**
  - 连击期间可通过 `burstAttackIntervalMult` 调整出手频率（<1 更快），结束即恢复

### 12. 出场震波 `enableShockwave`
- **参数**：`shockwaveRadius`（2）、`shockwavePushDistance`（1）、`shockwaveDamagePct`（0.3）
- **实际行为**：生成时对半径内敌人造成伤害，并沿远离方向推开指定距离（0.2 秒平滑位移）
- **注意**：只影响自己能攻击到的高度；击退距离设 0 = 只伤害不击退

### 13. 撕裂 `enableTear`
- **参数**：`tearDamagePerStack`（0.05）、`tearMaxStacks`（5）、`tearDuration`（4s）
- **实际行为**：每次命中叠加 1 层，目标受到的伤害 × `(1 + Σ各来源的层数 × 每层百分比)`；重复命中刷新持续时间
- **叠加（按兵种来源独立）**：
  - 同一兵种（`UnitTypeKey`）的重复命中只叠它自己那份（上限 `tearMaxStacks`）
  - 不同兵种各自一份，易伤**相加**
  - 例：5 号兵种 5 层 ×5% + 3 号兵种 4 层 ×3% → 受伤 ×1.37

### 14. 死亡燃烧 `enableBurnOnDeath`
- **参数**：`burnRadius`（2）、`burnDamagePct`（0.2/秒）、`burnDuration`（5s）
- **实际行为**：死亡位置生成火海区域，按每秒伤害持续灼烧经过的敌人
- **边界**：只烧**自己能攻击到的高度**（内部每 0.25 秒结算一次）

### 15. 群体攻击（溅射） `enableSplash`
- **参数**：`splashMode`（圆形 / 正面扇形）、`splashRadius`、`splashDamagePct`、`splashFacingAngle`、`splashFacingRotation`、`splashHitsPrimary`
- **两种形态**：
  - **圆形**：以「命中点在目标碰撞体上的接触点」为圆心，半径内造成百分比伤害
  - **正面扇形**：以自身朝向（可旋转偏转）为中心、指定角度内、且在自身攻击范围内的敌人全部命中
- **注意**：
  - 默认**主目标不吃**这次溅射伤害（`splashHitsPrimary` 可开）
  - 扇形每次攻击只触发一次，不随目标数量翻倍
  - 圆形形态的溅射圆心不是自身，也不是目标中心

### 16. 处决 `enableExecute`
- **参数**：`executeThreshold`（50，**绝对血量**）
- **实际行为**：造成伤害后，若目标血量**严格小于**阈值 → 立即死亡
- **边界**：
  - 必须**真实扣血**才判定；伤害被护盾/格挡**完全吸收**时不触发
  - **对建筑无效**（防止一刀秒基地）

### 17. 治疗 `enableHeal`
- **参数**：`healAmount`（30，固定值）、`healRadius`（0 = 用射程）、`healTargetHeight`、`healLowestHpFirst`
- **实际行为**：**治疗作为「攻击友军」走完整攻击流程**
  - 有受伤友军时，把它设为攻击目标：不在攻击距离就**走过去**，在距离内就**发起攻击**
  - 攻击帧到达时对该友军施加治疗（而不是伤害），随后进入正常攻击间隔
  - 没有伤员时，正常攻击敌人
- **频率**：跟随 `Stats.AttackInterval`；`healInterval` **已废弃**（字段保留但不再生效）
- **其他**：
  - 优先治疗血量百分比最低者
  - **可以治疗自己**
  - 多目标单位一次治疗**所有选中的友军**
  - 治疗**不会**触发溅射 / 眩晕 / 撕裂 / 冲锋 / 人海等攻击类被动
  - 飘字为绿色 `+N`
- **注意**：`healRadius` 决定「能选中多远的目标」，只有 `healRadius > 射程` 时才会出现"走过去再治疗"

### 18. 骑兵追远程 `enableCavalryChase`
- **参数**：`cavalryChaseRangeThreshold`（8）
- **实际行为**：
  - 搜索范围 = **max(自身射程 × 2, 5)**（边缘距离）
  - 优先锁定「射程 ≥ 阈值」的敌人；没有则回退到范围内最近的任意敌人
- **注意**：搜索范围**不是**自身攻击范围

### 19. 召唤师 `enableSummoner`
- **参数**：`summonPrefab`、`summonInterval`（8s）、`summonCountPerCast`（1）、`maxSummons`（5）、`summonOnKill`
- **实际行为**：
  - **定时召唤**：每 `summonInterval` 秒一次，要求：存活、未眩晕、召唤物数量 < 上限
  - 每次召唤生成 `summonCountPerCast` 只，**受 `maxSummons` 剩余额度限制**（剩余不足时只生成能容纳的数量）
  - 多只时沿水平方向**左右排开**（0 / +0.8 / -0.8 / +1.6 … 格），避免完全重叠
  - 召唤需要播动画：动画开始时**记录位置并让召唤师站定**，召唤帧在记录位置生成
  - 若召唤瞬间正在攻击，则**不播动画、直接生成**
  - **击杀召唤**：击杀敌人时在其死亡位置生成**固定 1 只**（受 `summonOnKill` 控制）；**召唤物击杀不会再触发**（防连锁）
- **注意**：
  - 眩晕会取消本次召唤
  - 召唤物生成点为召唤师**碰撞箱中心**（引导期间不会移动，因此不会偏移）
  - 引导有超时兜底（约 0.9 × 间隔 + 0.3 秒），防止动画事件丢失导致永久站定

### 20. 飞扑 `enablePounce`
- **参数**：`pounceRange`（8）、`pounceDuration`（0.35s）、`pounceArcHeight`（1.5）、`pounceInvulnerable`（关）、`pounceInterruptible`（开）
- **实际行为**：
  - 目标在**攻击射程之外**、且在 `pounceRange` 之内时，沿**抛物线**跃向目标
  - **落点 = 射程边缘**，落地即可攻击（落地后下一帧自动接普攻）
  - 飞行期间**无视碰撞**（可跨过前排单位/地形）
  - 落地后**重新吸附回路径**
- **可选项**：
  - `pounceInvulnerable`：飞行期间无敌（结束自动恢复）
  - `pounceInterruptible`：能否被眩晕打断（打断后就地落地，不平移）
  - `pounceBlockOneShotAnim`（默认开）：飞行期间屏蔽其他一次性动画（死亡与飞扑本身除外），避免"边飞边播眩晕/震波"
- **动画**：`SimpleAnimator.pounceClip` 绑定剪辑后播放 `Pounce` 状态；控制器 `UnitBaseController` 已内置 `Pounce` 参数 / 状态 / 回 Idle 转移
- **注意**：
  - 只对**当前索敌目标**生效，不额外索敌；飞扑范围受点杀等「攻击范围接管」影响
  - 不扑建筑、只扑能攻击到的高度
  - 无冷却、无次数限制，满足距离条件即触发
  - 与冲锋叠加：飞扑本身不消耗冲锋，落地后的第一击照常消耗并退出冲锋

### 21. 流血 `enableBleed`
- **参数**：`bleedDamagePctPerSec`（0.3 = 30% ATK/秒/层）、`bleedDuration`（3s）、`bleedMaxStacks`（3）
- **实际行为**：命中敌人时施加流血；每秒聚合结算一次伤害（`DamageType.Burn`）
- **叠加（按来源独立）**：
  - 每个施加者各占一份，互不干扰（A 的流血 3 层 + B 的流血 2 层 → 同时生效）
  - 同一来源重复命中只叠它自己那份的层数（上限 `bleedMaxStacks`）
  - 每秒伤害 = 所有来源的 `每层伤害 × 层数` **相加**
- **受伤刷新**：
  - 目标**受到真实伤害**时，所有流血实例的持续时间全部刷新为各自的基础时长
  - **流血自身的每秒伤害不触发刷新**（否则会永久自续）
  - 被护盾/格挡**完全吸收**（血量没变）不刷新
  - 只要持续受到伤害，流血就**不会结束**——这是与「燃烧」的核心区别
- **其他**：来源死亡后其流血继续生效（只是不能再叠层）；来源数量**无上限**
- **边界**：结算时会走盾墙减伤与护盾吸收

### 22. 燃烧 `enableIgnite`
- **参数**：`igniteDamagePctPerSec`（0.2）、`igniteDuration`（4s）、`igniteMaxStacks`（5）、`igniteSpreadRadius`（3）、`igniteSpreadDwell`（1.5s）
- **实际行为**：命中点燃目标；每秒按 `Σ(各来源层数 × 每层伤害)` 结算一次（`DamageType.Burn`）
- **叠加（按兵种来源独立）**：
  - 同一兵种的重复命中只叠它自己那份（上限 `igniteMaxStacks`）
  - 不同兵种各自一份，每秒伤害**相加**
  - 例：5 号兵种 4 层 ×5/秒 + 3 号兵种 5 层 ×3/秒 = 35/秒
- **蔓延**：燃烧中的单位累计"附近有同阵营单位"的时间，达到 `igniteSpreadDwell` 后点燃范围内**同阵营**单位；中途没人则计时清零；蔓延沿用来源兵种的数值与标识，被蔓延者刷新时间并叠层

### 23. 损伤 `enableImpair`
- **参数**：`impairSlowPercent`（0.3）、`impairDuration`（2s）
- **实际行为**：命中施加减速，独立计时，到期恢复
- **与光环关系**：两者走同一个减速通道，**取更强**（不叠加、不相乘）

### 24. 重击 `enableHeavyStrike`
- **参数**：`heavyStrikePushDistance`（1.5）
- **实际行为**：命中时**打断目标当前攻击**，并沿远离自身方向平滑击退指定距离
- **注意**：击退无视碰撞（与君王光环一致）

### 25. 过热 `enableOverheat`
- **参数**：`overheatAtkPctPerSec`（0.1）、`overheatMaxBonusPct`（1.0）、`overheatRetainDuration`（3s）
- **实际行为**：
  - 两次攻击间隔 ≤ `1.5 × 攻击间隔` 视为「持续攻击」，累计时间每满 1 秒提升一档攻击力
  - 攻击力加成有上限
  - 停止攻击后保留 `overheatRetainDuration`，到期**立即清零**
- **注意**：加成通过 Buff 实时作用于 `ATK`，会影响所有按攻击力计算的伤害

---

### 26. 领袖 `enableLeader`
- **参数**：`leaderRadius`（4）、`leaderAtkPct`（0.2）、`leaderAttackSpeedPct`（0.2）、`leaderMoveSpeedPct`（0.15）、`leaderAffectSelf`（关）
- **实际行为**：每 0.25 秒扫描半径内**同阵营**单位，为其挂上三条 Buff：
  - 攻击力 × `(1 + leaderAtkPct)`
  - 攻击间隔 × `1 / (1 + leaderAttackSpeedPct)`（+20% 攻速 = 间隔 ÷1.2）
  - 移动速度 × `(1 + leaderMoveSpeedPct)`
- **边界**：
  - **默认不含自己**（`leaderAffectSelf` 可开）
  - 友军**离开范围立即移除**加成；领袖阵亡 / 回池也会立即移除
  - **多名领袖可叠加**（各自一套 Buff，乘算）
  - 不计建筑

| 被动 | 旧描述的问题 | 实际情况 |
